# Maite · Nuestra historia

Abre index.html para ver la web. Mantén style.css, script.js y la carpeta img junto al HTML.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub y sube el contenido de esta carpeta. index.html debe quedar en la raíz del repositorio, junto a img/.
2. En Settings → Pages, selecciona Deploy from a branch.
3. Selecciona main y /(root), y pulsa Save.
4. Cuando termine la publicación, GitHub mostrará la dirección de tu web en esa misma sección.

Guía oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Personalizar

La carta de Cristóbal está incorporada completa: puedes cambiarla en index.html, dentro de la sección con id="carta". Las fechas del álbum se tomaron de los nombres de las fotos; no representan necesariamente el comienzo de la relación.

Las 33 fotos conservan sus nombres originales en img/. La web no necesita instalaciones ni compilación. Las fuentes de Google requieren internet; sin conexión se usan fuentes del sistema.
